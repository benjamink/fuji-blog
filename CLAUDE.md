# FujiNet Apple IIc Markdown Blog

A client/server application for writing and publishing blog posts from an Apple IIc with FujiNet hardware. The Apple IIc client allows authors to compose Markdown posts, manage categories, and toggle publish state. The Python FastAPI server persists posts, renders Markdown to HTML, and serves a React-based admin and public blog frontend.

## Quick Start

### Server Setup

1. **Install dependencies** using `uv`:
   ```bash
   cd server
   uv sync
   ```

2. **Run the FastAPI server**:
   ```bash
   uv run uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
   ```
   - API endpoints: `http://localhost:8000/api/*`
   - Admin UI: `http://localhost:8000/` (serves React frontend after build)
   - Swagger docs: `http://localhost:8000/docs`

3. **Build and serve the React frontend**:
   ```bash
   cd frontend
   npm install
   npm run build
   # Built files go to dist/ and are served by FastAPI on /
   ```

### Apple IIc Client Build

1. **Build for Apple II**:
   ```bash
   cd client
   make apple2
   ```

2. **Output**:
   - Built executable: `client/build/apple2/r2r/fuji_blog` (or disk image depending on platform)
   - Transfer to Apple IIc via FujiNet or create a bootable disk

3. **Configure FujiNet library** (if needed):
   - Set `FUJINET_LIB` in `client/Makefile` to a version number, local path, or git URL
   - Example: `FUJINET_LIB = 4.7.6` or `FUJINET_LIB = /path/to/fujinet-lib`

## API Specification

### Blog Post Model

```json
{
  "id": "uuid or timestamp-based string",
  "title": "Post Title",
  "slug": "post-title-auto-generated",
  "markdown_body": "# Heading\n\nContent...",
  "categories": ["category1", "category2"],
  "published": false,
  "created_at": "2026-05-19T12:00:00Z",
  "updated_at": "2026-05-19T12:00:00Z"
}
```

### Endpoints

#### List Posts
- **GET** `/api/posts` — List all posts (admin view; includes unpublished)
- **GET** `/api/posts/published` — List published posts only (public view)

#### Get Single Post
- **GET** `/api/posts/{id}` — Fetch a post by ID (admin)

#### Create Post
- **POST** `/api/posts`
  - Body: `{ "title", "markdown_body", "categories", "published" }`
  - Returns: Created post with auto-generated ID and timestamps

#### Update Post
- **PUT** `/api/posts/{id}`
  - Body: `{ "title", "markdown_body", "categories", "published" }`
  - Returns: Updated post

#### Delete Post
- **DELETE** `/api/posts/{id}` — Remove a post

#### Toggle Publish State
- **PATCH** `/api/posts/{id}/publish` — Set or toggle published status
  - Body: `{ "published": true|false }`

#### Render Markdown
- **POST** `/api/render`
  - Body: `{ "markdown_body": "..." }`
  - Returns: `{ "html": "..." }`

## Client Features

### Main Menu
1. **List Posts** — View published posts or all posts (admin mode)
2. **New Post** — Create a new unpublished post
3. **Edit Post** — Modify an existing post
4. **Toggle Publish** — Publish or unpublish a post
5. **Delete Post** — Remove a post
6. **Network Status** — Check FujiNet connectivity

### Workflows

**Writing a New Post:**
1. Select "New Post"
2. Enter title
3. Add categories (comma-separated)
4. Enter Markdown content (with simple editor)
5. Save as draft (published=false)
6. Confirm server sync

**Publishing a Post:**
1. Select "Edit Post" or "List Posts"
2. Choose a draft post
3. Select "Toggle Publish" to mark it as published
4. Changes sync to server immediately

**Editing:**
1. Select "Edit Post"
2. Choose a post from the list
3. Modify title, categories, or Markdown body
4. Save changes (server updates)

## Development

### Add New Server Features

1. Update `app/schemas.py` with new request/response models
2. Add handler in `app/main.py` with appropriate route and logic
3. Update `app/storage.py` if persistence logic changes
4. Test with `curl` or Postman
5. Update React UI in `frontend/src/api.ts` and components to consume the endpoint

### Add New Client Features

1. Create new `.c` file in `client/src/`
2. Declare in `main.c` or a header
3. Recompile with `make apple2`
4. Test on Apple IIc or emulator

### Environment Variables

- **Server**:
  - `DATA_DIR`: Path to store `posts.json` (default: `server/data`)
  - `HOST`: Server host (default: `0.0.0.0`)
  - `PORT`: Server port (default: `8000`)

- **Client**:
  - Set server URL and FujiNet device configuration in the client UI menu or hardcoded constants

## Troubleshooting

### Server won't start
- Check Python version: `python --version` should be 3.10+
- Verify `uv` is installed: `uv --version`
- Reinstall dependencies: `uv sync --refresh`

### Client build fails
- Ensure cc65 toolchain is installed (for Apple II builds)
- Check `FUJINET_LIB` path in `client/Makefile`
- Run `make clean` and retry

### FujiNet client can't connect
- Verify FujiNet device is online and reachable
- Check server is running and firewall allows traffic
- Confirm server URL is correct in client code
- Enable debug output in `client/src/network.c` (if available)
